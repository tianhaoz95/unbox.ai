# 5 · 预训练

## 预训练的作用

预训练是在海量语料库中教会模型预测下一个 Token 的过程。模型处理数十亿 Token，调整权重以对可能的续写内容赋予更高概率。预训练结束后，模型将训练语料的统计规律压缩到了参数中 —— 它可以生成流畅的文本，但尚无法理解和遵循指令。

## 学习率调度

```
学习率
▲
│      ╭──────────────────────────╮
│     ╱                            ╲
│    ╱                              ╲___________
│___╱
└──────────────────────────────────────────────▶ 步数
   预热（2k步）      余弦衰减               下限
```

余弦调度将学习率从 `max_lr` 平滑衰减至 `max_lr × min_lr_ratio`。预热阶段防止训练初期模型权重随机时出现过大的梯度更新。

## 混合精度：bfloat16

训练通过 `torch.amp.autocast` 在 bfloat16 精度下进行前向和反向传播。bfloat16 的优势：

- 与 float32 具有相同的指数范围 → 无溢出/下溢问题
- 占用 float32 一半内存 → 支持更大批次
- 在现代 NVIDIA GPU（A100、H100、GB10）上原生加速

优化器状态（动量、方差）保持 float32 精度以确保数值稳定性。

## 分布式训练

训练循环使用 Megatron-Core 进行分布式状态管理。当前运行使用单 GPU 的 DDP（数据并行）—— `setup_model()` 抽象设计为张量并行和流水线并行可在后续以加法方式叠加。

## 检查点

每 1,000 步保存一次检查点到 `checkpoints/pretrain/760m/`。每个检查点包含：

- 模型状态字典
- 优化器状态字典
- 步数和 epoch 计数器
- 最新损失值

`latest.json` 指针追踪最近的检查点，便于恢复训练。

**恢复正确性：** 恢复时，系统计算已消费的块数（`step × batch_size × grad_accumulation_steps`），数据集迭代器向前跳过相应数量，确保同一 epoch 内不重复训练任何数据。

## 预训练产出

一个**基础模型**：能够生成流畅、连贯的文本，但不具备遵循指令的能力。用问题提示它时，会以问题的风格继续生成文本，而非给出答案。指令跟随能力需要通过 SFT 获得。
