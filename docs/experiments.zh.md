# 计划中的实验

这是一份在核心平台验证后计划运行的研究实验清单（持续更新）。每个实验位于（或将位于）`unbox/` 目录下，并从 `unbox_platform/` 导入基础组件。

## 架构实验

| 实验 | 描述 | 状态 |
|---|---|---|
| **混合专家（MoE）** | 用稀疏 MoE 路由替换稠密前馈网络；在参数量相同时比较质量与计算量 | 计划中 |
| **滑动窗口注意力** | 用滑动窗口注意力（Mistral 风格）替换完整因果注意力，提升长上下文效率 | 计划中 |
| **多头潜在注意力（MLA）** | DeepSeek-V2 通过低秩投影压缩 KV 缓存的方案 | 计划中 |
| **差分 Transformer** | 用差分注意力替换 Softmax 注意力，提升噪声消除能力 | 计划中 |

## 训练实验

| 实验 | 描述 | 状态 |
|---|---|---|
| **Muon 优化器** | 对权重矩阵使用正交化梯度下降；与 AdamW 对比收敛速度 | 计划中 |
| **YaRN 长上下文扩展** | 通过 RoPE 频率插值将有效上下文长度扩展到 `max_seq_len` 之外 | 计划中 |
| **预热-稳定-衰减（WSD）调度** | 余弦衰减的替代方案，包含一个稳定阶段用于中间训练检查点 | 计划中 |

## 数据实验

| 实验 | 描述 | 状态 |
|---|---|---|
| **课程学习** | 按难度排序训练样本，先训练简单样本 | 计划中 |
| **领域上采样** | 在训练中对高质量领域（数学、代码、科学）进行过采样 | 计划中 |
| **合成数据增强** | 使用教师模型从 FineWeb-Edu 生成合成问答对 | 计划中 |

## RL 实验

| 实验 | 描述 | 状态 |
|---|---|---|
| **数学 GRPO** | 使用 GRPO 配合可验证奖励（精确答案匹配）提升数学推理能力 | 计划中 |
| **宪法 AI** | 自我批评循环：模型批评自己的回复，然后修改 | 计划中 |
| **长度惩罚** | 添加长度奖励信号，在不牺牲质量的情况下减少冗长输出 | 计划中 |

## 推理实验

| 实验 | 描述 | 状态 |
|---|---|---|
| **投机解码** | 使用小型草稿模型提议 Token，再用大模型并行验证 | 计划中 |
| **量化（INT8、FP8）** | 对权重和/或激活值进行训练后量化；测量质量损失 | 计划中 |
| **前缀缓存** | 基准测试基数树前缀共享在真实工作负载下的 KV 缓存命中率提升 | 计划中 |

---

!!! tip "贡献实验"
    在 `unbox/<实验名>/` 下创建目录，包含自洽的 `README.md`、入口点和配置文件。从 `unbox_platform/` 导入基础组件，而非复制代码。实验不要求具有通用性 —— 只需正确且可复现即可。
