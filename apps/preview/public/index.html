curriculum

Seven modules.
The full stack.

Each module is a self-contained, readable implementation — one file you can open, read top-to-bottom, and modify. Import what you need. Swap what you want.

unbox/tokenizer/
01
Tokenizer
BPE from scratch. Byte-level encoding, merge rules, vocabulary construction. No HuggingFace wrappers — just bytes becoming tokens.
32K vocab · BPE
unbox/data/
02
Data Pipeline
JSONL ingestion, sequence packing, batching. The exact pipeline that feeds real pretraining runs — every step is a readable function.
FineWeb-Edu · packing
unbox/train/
03
Pretraining
A real 760M parameter model. GQA, RoPE, SwiGLU, RMSNorm, Flash Attention. 3D parallelism via Megatron-Core. Sanity checks at every milestone.
760M · GQA · Flash Attn
unbox/sft/
04
Supervised Fine-tuning
Chat-template SFT via TRL. One "messages" column, correct token masking, per-device configs. The bridge from base model to assistant.
TRL · SFTTrainer
unbox/rl/
05
RL Post-training
DPO and GRPO offline. PPO online via OpenRLHF. Verifiable reward RL. The full post-training stack, dissected and documented.
DPO · GRPO · PPO
unbox/distill/
06
Distillation
Logit matching, hidden-state distillation, reasoning transfer. Compress a large teacher into a small, deployable model you actually own.
GKD · logit matching
unbox/infer/
07
Inference Engine
Paged KV cache, continuous batching, disaggregated prefill-decode, Triton kernels, tensor parallelism via NCCL. A full engine — readable.
Triton · ZMQ · NCCL
why unbox.ai

Built for engineers
who read source.

Not a tutorial. Not an API wrapper. A complete, working implementation you can read, run, fork, and break on purpose.

▤
Single-file components
RMSNorm, RoPE, attention, FFN — each lives in one file. Open it, read it, understand it. No hunting through 40-file class hierarchies to find where the math happens.
◈
Real model. Real results.
A 760M parameter model trained on FineWeb-Edu with documented sanity checks at step 10k and 15k. Not toy examples — production-grade configs you can reproduce.
⌥
Lego-piece architecture
Every component is individually importable. Swap one atom out of a molecule, run your experiment. The boundary between stable platform and research lab is principled and explicit.
⬡
Design docs for every layer
Architecture decisions are written down — why Megatron-Core, why Triton, why disaggregated inference. The reasoning is part of the curriculum, not locked in someone's head.
from day one

Run a real
training loop
in minutes.

Download the data, train the tokenizer, launch pretraining. Every command maps to code you can read. No magic, no hidden config.

unbox.ai — terminal
$python -m unbox_platform.data.prepare \
  --output data/fineweb.jsonl
Streaming 10B tokens from FineWeb-Edu...
✓ 10,240,000,000 tokens saved

$python -m unbox_platform.tokenizer.train \
  --data data/fineweb.jsonl --output checkpoints/tok
✓ 32K vocab BPE tokenizer trained

$torchrun --nproc_per_node=8 \
  -m unbox_platform.train.pretrain \
  --config configs/pretrain/760m.yaml
